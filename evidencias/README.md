# Evidencias del servidor Express

1. Copia `server/.env.example` como `server/.env` y configura la URL y la clave pública de Supabase.
2. Desde la raíz del proyecto ejecuta `npm install` y luego `npm start`.
3. Desde otra terminal ejecuta `npm run evidence`. Genera un reporte HTTP sin guardar ni imprimir la clave de Supabase.
4. Las capturas de la página principal y del estado del servidor ya están guardadas en esta carpeta.

El reporte se crea como `resultado-servidor.md` al ejecutar el verificador. Si vuelves a tomar capturas, guárdalas en esta carpeta.
